changes are overwritten the next time it runs.

**For the voice actor.** Read each line in the *Text to read* column, in a
warm, clear, unhurried voice, as Ada talking to a child. Save it as
`<File name>.ogg` (or `.mp3` or `.wav`), exactly as spelled in the first
column. The *Look* column says which book the line is for: `gentle` is the
storybook, `exceptional` is the grown-up treatise. Lines are in book order.

**To use a recording**, put the file in `assets/voice/` and run the command
again. The page plays a real recording first, then the placeholder, then
the browser's own voice.
