# Palette (locked 2026-10-10)

Draw only with these colours. The code swaps them by name for each look,
so a drawing made in Parchment also works in the Exceptional look.
Inkscape palette files: `art/primer-parchment.gpl`, `art/primer-byrne.gpl`.

## Gentle: Parchment

| name | hex | use |
|---|---|---|
| `paper`       | `#F4E9D0` | page, empty insides of shapes |
| `paper-shade` | `#E6D5B0` | aged edges, soft shadows |
| `ink`         | `#3B2A1E` | every outline, lines, numbers (iron-gall ink brown) |
| `ink-soft`    | `#7A6450` | faded ink: secondary lines, ticks |
| `warm`        | `#B07A4A` | main fill: leather pouch, wood, machine body |
| `bright`      | `#D9A441` | gold: coins, things to look at |
| `mark`        | `#A63D2F` | highlights and glows (red ochre, like the red ink old books used for emphasis) |

## Exceptional: Byrne's Euclid

| name | hex | replaces |
|---|---|---|
| `paper` | `#F3EBD6` | paper, paper-shade |
| `ink`   | `#1E1A16` | ink, ink-soft |
| `red`   | `#C8321E` | mark |
| `yellow`| `#E3A72F` | bright |
| `blue`  | `#1F4E8C` | warm |
